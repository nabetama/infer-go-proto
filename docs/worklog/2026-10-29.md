## Task 2: 名前の変換 (internal/mangle)

- `Pkg` `Type` `Func` `RT` `Table` を追加した。関数名はすべて `::` を含む 1 つのトップレベル識別子。
- go/ssa の関数リテラルの名前は `Top$1` の形なので、親の名前に続けて `$1` を付けている。
- 値レシーバのメソッドの `(*T).M` ラッパーは元の名前と衝突するため、`$wrapper` `$bound` `$thunk` を末尾に付ける。
- ジェネリック関数のインスタンスは `Pkg::Name$arg$`、インスタンス化された型のメソッドは `Type(recv)$Name`。

## Task 3: Textual の中間表現と出力

- `internal/sil` に Module、Proc、命令、式、終端の型と `(*Module).WriteTo` を追加した。
- 同じ名前の型宣言と declare は、内容が同じなら 1 つだけ出力し、内容が違えば WriteTo がエラーを返す。
- Infer の `npe.sil` の `basic_bad` 相当を Module で組み立て、期待値 `testdata/basic_bad.sil` との一致と、Infer が NULLPTR_DEREFERENCE を 1 件報告することをテストで確かめた。

## Task 4: Go のコードの読み込みと型の変換

- `translate.Load` が `packages.Load` と `ssautil.AllPackages`(NaiveForm | InstantiateGenerics) で SSA を作る。読み込みエラーは error で返す。
- `typeConv` が Go の型を Textual の型に変換し、参照された型の宣言を集める。再帰する struct は宣言の名前を先に登録して止める。`Decls()` は名前順。
- 配列は slice と同じ `*go::slice`、型パラメータは `*go::opaque` にしている。無名 struct は `go::struct$<Go の表記>$` という名前で宣言する。
- `connectrpc.com/connect` を go.mod に追加した。テスト用の参照元は `testdata` 配下なので、`types_test.go` の空 import で go.mod に残す。
