# 2026-10-28

## 決めたこと

- Go を Infer で解析できるようにする。方法は、Go で書いた変換ツールで `go/ssa` から Textual（`.sil`）を出力し、`infer --capture-textual` に渡すもの。LLVM ビットコードを経由する方法（gollvm / TinyGo → Infer の llvm フロントエンド）は、Infer の llvm フロントエンドが Swift 向けに調整されているため採らない。
- 最初に検出するものは「外部入力が危険な処理に届くもの」（taint）。リソースの閉じ忘れや nil による panic は後回し。
- 想定する構成は、connect / gRPC のハンドラを入力元、bun / `database/sql` の SQL 文字列引数を危険な関数とするもの。
- リポジトリは公開予定。サンプルは汎用的な例だけで書く。

## 調べたこと

- facebook/infer の最新リリースは v1.3.0（2026-05-12）。バイナリは `infer-osx-arm64-v1.3.0.tar.xz` と `infer-linux-x86_64-v1.3.0.tar.xz`。
- 手元の環境は Go 1.27.3（darwin/arm64）。Infer は未インストール。
- `infer/src/` のフロントエンドは clang、java、erlang、python、rust、llvm（Swift）など。go はない。
- 外部の言語を足す方法として、issue facebook/infer#2045 でメンテナが `.sil` を出力して `--capture-textual` で取り込む方法を案内している。
- Pulse の taint 設定の仕様は `infer/src/atd/pulse_config.atd`。`taint_target` に `ArgumentPositions` などがある。
- `PulseTaintOperations.ml` の `taint_initial` が、入力元に指定した関数の引数に taint を付ける。
- Textual の `.source_language` に Go はない（`Textual.ml` の `Lang`）。

## 設計のレビュー

別のエージェントに設計だけを読ませ、作るうえで足りない情報を挙げさせた。

- ユーザーが決めたこと: サンプルは本物の connect / gRPC / bun を使う。入力元はハンドラ名ではなく引数の型で決める。
- 設計時に判断したこと:
  - v1.3.0 で動かなければ main をソースからビルドする。
  - 可変長引数と `MakeInterface` を変換の対象にする。
  - `bun.Safe` のような型への変換は、本体のない関数の呼び出しとして出力する。
  - テストでは、変換できなかった警告が出ていないことも確かめる。
