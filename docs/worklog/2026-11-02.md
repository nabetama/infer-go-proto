### Task 8 の修正

- `.inferconfig` の `database_sql::DB` を `database::sql::DB` に直した（`/` は `::` になる）。`*sql.DB` の `QueryContext` を使う `SearchUsersSQLBad`（報告する）と `SearchUsersSQLGood`（報告しない）を `grpcsvc` に足した。`query` が 2 番の引数であることは go2sil が出力した宣言で確かめた。
- 入力元を `connectrpc_com::connect::Request` だけにしても、`GetUserBad` は報告された。qualifier は「`Handler$GetUserBad` の引数 `#2`（`req`）から `SelectQuery$Where` の引数 `#1` へ」で、本体のない `GetName` を通って taint が伝わっている。
- 生成された message の型の入力元を、型の名前の列挙から生成コードのパッケージのパス `github_com::nabetama::infer_go_proto::examples::gen::user::v1::` に変えた。理由と、他のコードに使うときに書き換える箇所は設計ドキュメントに書いた。
- `append` は `unsupported *ssa.Call` になるので、サンプルでは使わない。
